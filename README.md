# Pack Opening — concept demo

Concept prototype of a 3D booster-pack opening feature, built for a website pitch.
Not affiliated with, endorsed or sponsored by The Pokémon Company, Nintendo, Creatures Inc. or GAME FREAK inc.
Pokémon names, pack artwork and card images belong to their owners and are shown here only to illustrate the concept.

**Live demo:** https://anhnguyenit8-nadilac.github.io/pokemon-pack-opening-demo/

Tips: add `#en`, `#zh` or `#ja` to the URL to pick a language; `#ja-rr` forces a Double Rare in the last slot.

Built with Three.js (vendored in `vendor/`). Run locally with `python3 -m http.server` and open the printed address.
